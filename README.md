# API Schema Validation Kit

مجموعة من الأدوات والأعمال العملية الصغيرة التي أقوم بتطويرها باستخدام JavaScript وAPI وJSON Schema.

## ما الذي يتضمن هذا المشروع؟

- API Schema Validation Kit
  - أداة للتحقق من بيانات API قبل الوصول إلى النظام.
  - تعتمد على JSON Schema وAJV.

- To-Do App
  - تطبيق قائمة مهام مع حفظ محلي.
  - يدعم الفلاتر، الحذف، الإكمال، والوضع الليلي.

- Joke Generator
  - مولّد نكات عشوائية عبر API عام.
  - يعمل مباشرة في المتصفح.

- Weather Dashboard
  - لوحة طقس عربية باستخدام OpenWeatherMap API.
  - تعرض الحالة الحالية والضغط والرطوبة وسرعة الرياح والتوقعات.
