# Focus Tasks

A responsive to-do list application with local-storage persistence.

## Features

- Add, complete, delete, and clear completed tasks
- All, Active, and Completed filters
- Automatic persistence using `localStorage`
- Persistent light/dark theme preference
- Keyboard-friendly controls and responsive layout

## Run locally

Open `index.html` in a browser, or run:

```bash
cd todo-app
npx serve .
```
