# Focus Tasks

A simple responsive to-do app for managing daily tasks in the browser.

## Features

- Add new tasks
- Mark tasks as complete or active
- Delete single tasks
- Clear all completed tasks
- Filter tasks by status
- Save tasks using `localStorage`
- Persist light/dark mode preference
- Responsive layout for desktop and mobile

## Run locally

Open the file directly in a browser or run a local static server:

```bash
cd todo-app
npx serve .
```

Then open the local URL shown in the terminal.

## Notes

This app is a demo project inside the `api-schema-validation-kit` repository and is intended to showcase a simple frontend UI pattern rather than a production SaaS app.
