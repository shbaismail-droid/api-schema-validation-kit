# لوحة الطقس

تطبيق لوحة طقس عربي باستخدام OpenWeatherMap API.

## المزايا

- البحث عن أي مدينة عربية أو إنجليزية
- درجة الحرارة الحالية
- الرطوبة
- سرعة الرياح
- الضغط الجوي
- الإحساس الحراري
- أيقونة حسب حالة الطقس
- توقعات قصيرة المدى لمدة 5 أيام
- اتصال مباشر مع API العامة

## التشغيل

1. افتح الملف `weather-dashboard/index.html` في المتصفح.
2. أو شغّل خادمًا محليًا:

```bash
cd weather-dashboard
npx serve .
```

## ملاحظات

- يحتاج المتصفح إلى اتصال بالإنترنت.
- يتطلب API key من OpenWeatherMap.
- إذا رُفضت الطلبات بسبب 429 أو خطأ الشبكة، يظهر رسائل مناسبة.
