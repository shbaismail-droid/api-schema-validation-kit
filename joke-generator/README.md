# Laugh Lab

A responsive random joke generator powered by [JokeAPI](https://jokeapi.dev/).

## Features

- Fetches safe-mode one-liners and two-part jokes from an external API
- Loading, error, and offline states
- Copy the current joke to the clipboard
- Responsive, accessible interface with keyboard focus states
- No backend or API key required

## Run locally

Open `index.html` in a browser, or serve the folder with any static server:

```bash
cd joke-generator
npx serve .
```

The browser needs internet access to request jokes from JokeAPI.
